## 2. Tiered Voice Pipeline

### What Was Built

A two-tier voice architecture that routes users to cheap or premium voice pipelines based on subscription, reducing voice AI costs by ~95% for non-premium users.

### Files Created

| File | Purpose |
|---|---|
| `backend/app/services/whisper_stt.py` | Azure Whisper STT client — transcribes audio bytes to text, auto-chunking for large files |
| `backend/app/services/edge_tts_service.py` | Free Microsoft Edge TTS — text to MP3 via Edge Read Aloud (zero cost, no API key) |
| `backend/app/services/voice_router.py` | Tier-based orchestrator — routes Threshold/Inner Chamber to cheap path, Sovereign Circle to premium |

### Files Modified

| File | Changes |
|---|---|
| `backend/app/main.py` | Registered `VoiceRouter` in lifespan + `_service_checks` |
| `backend/requirements.txt` | Added `edge-tts~=7.2.0` |
| `.env.template` | Added `AZURE_WHISPER_ENDPOINT`, `AZURE_WHISPER_DEPLOYMENT`, `AZURE_WHISPER_API_VERSION`, `EDGE_TTS_VOICE` |
| `docker-compose.prod.yml` | Added Whisper + Edge TTS env vars |

### Pipeline Architecture

```
Cheap Path (Threshold + Inner Chamber):
  Audio → Azure Whisper STT → Text → Grok 4-1 Fast → Response → Edge TTS → Audio
  Cost: ~$0.001/min | Latency: ~2-3s

Premium Path (Sovereign Circle):
  Audio → Azure Realtime WebSocket (bundled STT+LLM+TTS) → Audio
  Cost: ~$0.08/min | Latency: <500ms
```

### Pending Integration

The `VoiceRouter.process_voice_message()` needs to be wired into `azure_bridge.py`'s `_can_use_realtime()` method so non-Sovereign Circle users are routed to the cheap path instead of being denied. Currently the VoiceRouter is initialized and healthy but the bridge integration is not yet connected.
