# Clinical Sovereignty Lab / Little Nate
# Cursor AI Context Rules

## Project Overview
This is Little Nate, an AI-powered therapy platform with:
- Flutter mobile app (client + coach portal)
- Python FastAPI backend with WebSocket bridge
- React admin console (Sovereign Command)
- Nevedal quantum emotional coherence engine
- Night School AI training system

## Tech Stack
- **Mobile**: Flutter/Dart with Riverpod state management
- **Backend**: Python 3.11+, FastAPI, asyncpg, WebSockets
- **Database**: PostgreSQL 15+
- **Cache**: Redis
- **AI**: Azure OpenAI GPT-4o Realtime
- **Payments**: Stripe (when enabled)
- **Admin**: React with Tailwind

## Architecture Pattern
- MVVM for Flutter (Models, ViewModels, Views)
- Service-based routing for Python (single WebSocket, message dispatch)
- Unidirectional data flow throughout

## Key Algorithms (DO NOT MODIFY without understanding)

### Nevedal Formula
```
C_emo(t) = [β · p_ent · T_tunnel] / [γ_env + E_G^(joint)/ℏ] × exp[-(γ_env + E_G^(joint)/ℏ) × t]
```
Located in: `backend/app/services/nevedal_engine.py`

### Voice Biometrics
Extracts: pitch_mean, pitch_variance, energy, speech_rate, pause_ratio
Located in: `backend/app/services/nevedal_engine.py` → `VoiceBiometricExtractor`

### PII Detection
Pattern-based detection for SSN, phone, email, addresses
Located in: `backend/app/services/night_school_director.py` → `PIIDetector`
