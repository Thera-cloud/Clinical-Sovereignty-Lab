# Family Sanctuary IAP Review Screenshots (20–23)

All screenshots in this folder are **6.7" iPhone App Store** dimensions (**1290 × 2796**) for App Store Connect submission. They show Family Sanctuary flows where the **$3** (Get Help / assisted response) and **$5** (individual coaching) consumables are offered; these are available via In-App Purchase on iOS.

| File | Content | IAP relevance |
|------|--------|----------------|
| **20** | First coaching FREE modal — “Get Coaching” / “No Thanks” | First coaching free; subsequent coaching uses IAP ($5) |
| **21** | Private coaching with Suggested Response, “Assisted response ready!” | Get Help ($3) consumable — push to chat |
| **22** | Coaching Checkpoint — “Return to Family”, “Get Help + Return ($3)”, “Continue Coaching ($5)” | Shows $3 and $5 options; both are consumable IAPs on iOS |
| **23** | Session Summary — Key Conflicts, Insights, Next Steps, balance | Session total reflects base fee + coaching/assisted/group charges |

**Apple Product IDs** (consumables):

- `net.sovereignsanctuary.sanctuary_charge_base_fee` — $20 initial session
- `net.sovereignsanctuary.sanctuary_charge_group_coaching` — $20 group coaching
- `net.sovereignsanctuary.sanctuary_charge_individual_coaching` — $5 individual coaching
- `net.sovereignsanctuary.sanctuary_charge_assisted_response` — $3 Get Help

**Note for review:** On iOS, when the user taps “Get Help + Return ($3)” or “Continue Coaching ($5)”, the native app presents the Apple IAP sheet for the corresponding consumable. These screenshots show the in-app UI that leads to those IAP flows.
