Ask Little Nate

Siri Shortcut for iOS, iPadOS & macOS

Say "Hey Siri, Ask Little Nate" followed by your question, and Nate will respond instantly through Siri. Works on iPhone, iPad, Mac, Apple Watch, and HomePod.
1 Tap the button below to add the shortcut
2 Allow the shortcut to run (it connects to Sovereign Sanctuary securely)
3 Say "Hey Siri, Ask Little Nate" or run from the Shortcuts app

Manual Setup

If the button doesn't work, create the shortcut manually:

  1. Open the Shortcuts app
  2. Tap + to create a new shortcut
  3. Add action: Ask for Input (Text, prompt: "What would you like to ask?")
  4. Add action: Get Contents of URL
  5. Set URL to: https://api.sovereignsanctuary.net/api/summon
  6. Method: POST
  7. Headers: Content-Type: application/json
  8. Body: JSON with message = Provided Input, channel = "siri"
  9. Add action: Get Dictionary Value → key: response
  10. Add action: Speak Text (or Show Result)
  11. Name it "Ask Little Nate"
