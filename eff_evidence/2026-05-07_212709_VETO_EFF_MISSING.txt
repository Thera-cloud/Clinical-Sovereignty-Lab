CODE PHASE (after HALT 1 approved)
═══════════════════════════════════════════════════════════════

Build new module: backend/app/services/therapeutic_controller.py

This module orchestrates per-turn state-dependent generation. Does NOT 
replace bridge_server.py — augments the response generation path.

Function: generate_therapeutic_response(
    user_input: str,
    user_id: str, 
    db_pool,
    conversation_context: dict
) -> dict

Flow:

PART 1 — Multi-signal autonomic state detection
Combine signals into one autonomic_state classification:
- Distress markers in text (regex patterns + linguistic shifts)
- Recent message length pattern (sudden brevity = activation/shutdown)
- Voice biometrics if available (consume nevedal_engine extractor)
- TMC class from existing tmc.py classify_tmc_moment
- Coherence score from nevedal_engine

Output: autonomic_state ∈ {regulated, in_window, activated, shutdown}

PART 2 — Recurring pattern detection (old wiring)
Use crystal_recall_bridge.recall_crystals_for_context with filtering:
- user_id scope
- Look for domains/themes with 3+ recurrences
- Combine with TMC RECURRENCE class signal

Output: encoded_patterns (list, may be empty)

PART 3 — Mismatch opportunity assessment
Mismatch only when ALL true:
- autonomic_state == 'in_window'
- encoded_patterns is non-empty
- TMC class in [THRESHOLD, BREAKTHROUGH, RECURRENCE]

Output: mismatch_available (bool) + which pattern to address

PART 4 — Context assembly via existing infrastructure
- recent_narratives: last 7 client_narrative_text from 
  sse_delivery_generation_log (query if pattern doesn't exist yet)
- relevant_crystals: recall_crystals_for_context filtered by current topic 
  + domain='neuroscience_foundations' for meta-therapeutic questions
- recent_messages: last 5 user turns for register continuity

PART 5 — Token cap by autonomic state
TOKEN_CAPS = {
    'shutdown': 200,      # bare presence, no demands  
    'activated': 350,     # short, regulating, no interpretation
    'in_window': 600,     # full conversational range (matches Phase 1)
    'regulated': 1500     # depth requested OR explicit operator override
}

These caps integrate with existing _select_max_tokens helper, not replace it.

PART 6 — System prompt composition
Compose with:
- DNA layer (load at startup from 
  docs/SOVEREIGN_SANCTUARY_DNA_NEUROSCIENCE_2026-05-07.md, cache module-level)
- Autonomic state guidance (state-specific instructions)
- Register default (WARM unless mismatch_available AND in_window)
- Bridge sentence requirement if shifting to CLINICAL
- Recent narratives for anti-repetition
- Relevant crystals for context
- encoded_patterns_to_address ONLY if mismatch_available

PART 7 — LLM generation
Reuse existing chat_completion_with_fallback infrastructure.
max_tokens from TOKEN_CAPS.
temperature=0.7.

PART 8 — Therapeutic post-audit
SEPARATE from EFF/system audit. Checks:
- WARM register honored when distress detected?
- Bridge sentence present if shifted to CLINICAL?
- Somatic invitation present when reactivation flagged?
- Banned phrases avoided? (list: "I sense...", "I want to acknowledge...", 
  "It takes courage", reflexive openers from Lisa transcript audit)
- Response under autonomic-appropriate token cap?
- Anti-repetition: no phrase overlap with last 7 narratives?

If audit fails: regenerate ONCE with violation injected into system prompt. 
If second attempt also fails: log critical failure, return original response 
(don't block production).

Log all audit results to new sse_therapeutic_audit_log table.

PART 9 — Reconsolidation event tracking
If mismatch_available AND post-audit detects mismatch was delivered:
- Log potential reconsolidation event
- Becomes CEEEvent candidate for nevedal_engine
- Data collection only, not user-visible

DATABASE MIGRATION
═══════════════════════════════════════════════════════════════

New migration: backend/migrations/201_therapeutic_audit_log.sql

CREATE TABLE IF NOT EXISTS sse_therapeutic_audit_log (
    audit_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    user_id TEXT NOT NULL,
    timestamp TIMESTAMPTZ DEFAULT NOW(),
    autonomic_state TEXT,
    tmc_class TEXT,
    register_used TEXT,
    mismatch_attempted BOOLEAN,
    mismatch_delivered BOOLEAN,
    audit_passed BOOLEAN,
    audit_violations JSONB,
    response_token_count INTEGER,
    encoded_patterns JSONB
);

CREATE INDEX IF NOT EXISTS idx_audit_log_user 
ON sse_therapeutic_audit_log(user_id, timestamp DESC);

CREATE INDEX IF NOT EXISTS idx_audit_log_failures
ON sse_therapeutic_audit_log(timestamp DESC) 
WHERE audit_passed = false;
